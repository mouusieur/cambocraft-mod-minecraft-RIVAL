# Guide joueur — brouillon

Cambocraft n'est pas jouable : aucun portail, zone, PNJ, pouvoir, recette ou événement n'est disponible. Ce document n'est pas un guide d'installation d'une version distribuable. Le plan de progression figure dans `DESIGN.md` ; les probabilités du seul simulateur expérimental figurent dans `PROBABILITES.md`.

Un guide complet (progression réelle, économie, cuisine, pêche, saisons et événements) doit être rédigé et testé contre le contenu effectivement livré.
